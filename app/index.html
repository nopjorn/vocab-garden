            มีอะไรใหม่ ✨

            ประวัติการเปลี่ยนแปลงของ Vocab Garden เวอร์ชันใหม่อยู่บนสุด

            โหลดประวัติไม่ได้ในตอนนี้ (อาจกำลังออฟไลน์) ดูได้ที่ CHANGELOG บน GitHub

            ตั้งค่า

            รู้ศัพท์ด่านแรก ๆ อยู่แล้วใช่ไหม? เลือกด่านที่อยากเริ่ม คำใหม่จะมาจากด่านนี้เป็นต้นไป คำที่ถึงเวลาทวนยังมาตามปกติ และแตะที่ด่านในหน้าหลักเพื่อเรียนเฉพาะด่านนั้นได้เสมอ

            เสียงอ่าน

            บางเครื่อง (เช่น iPhone) อาจต้องแตะหน้าจอหนึ่งครั้งก่อน เสียงจึงจะเล่นอัตโนมัติ เสียงมาจากเครื่องของคุณ ถ้าไม่ได้ยินให้เช็คว่าไม่ได้ปิดเสียงเครื่องไว้

            วิธีทวน

            "ผสมหลายแบบ": คำใหม่ยังเป็นการ์ดให้ดูก่อน ต้นอ่อน 🌱 ตอบด้วยการเลือกคำแปล ต้นกำลังโต 🌿 เติมคำที่หายไปในประโยคตัวอย่าง ส่วนต้นไม้ใหญ่ 🌳 ดูคำแปลไทยแล้วพิมพ์คำอังกฤษเอง (ถ้าไม่อยากพิมพ์ ปิดช่องด้านบนได้ ต้นไม้ใหญ่จะเติมคำแทน) ตอบถูกนับเป็น "จำได้แม่น" ตอบผิดหรือกด "ไม่รู้" นับเป็น "ยังจำไม่ได้" พิมพ์ถูกแต่ใช้ตัวช่วยใบ้ หรือสะกดผิดแค่ตัวเดียว นับเป็น "พอจำได้" การนึกคำเองช่วยให้จำได้นานกว่าการพลิกดูคำแปลอย่างเดียว

            นิสัยการท่อง

            นับเป็นจำนวนครั้งที่ตอบ ถ้าคำค้างทวนเยอะกว่าเพดาน แอปจะทยอยทวนวันละส่วน (เริ่มจากคำที่ค้างนานสุด) และงดคำใหม่ชั่วคราวจนกว่าคำค้างจะเบาลง ตั้ง "ไม่จำกัด" ถ้าอยากทวนให้หมดในวันเดียว การแตะเรียนเฉพาะด่านจากหน้าหลักไม่ถูกจำกัดด้วยเพดานนี้

            ความสนุก

            ปิดไว้เป็นค่าเริ่มต้น เผื่อคุณท่องในที่สาธารณะ เสียงสร้างในเครื่องไม่มีการโหลดอะไรเพิ่ม แรงสั่นใช้ได้เฉพาะ Android (iPhone ไม่รองรับ) ส่วนคอนเฟตตีจะหยุดเองถ้าเครื่องตั้ง "ลดการเคลื่อนไหว"

            หน้าตา

            สำรองความคืบหน้า

            ความคืบหน้าเก็บอยู่ในเครื่องนี้เท่านั้น ดาวน์โหลดไฟล์สำรองเก็บไว้ หรือใช้ย้ายไปเครื่องอื่นได้

            💡 บน iPhone และ iPad: Safari กับแอปที่เพิ่มไว้บนหน้าจอโฮมเก็บข้อมูลแยกกัน แนะนำให้เปิดจากไอคอนบนหน้าจอโฮมเป็นหลัก ถ้าจะย้าย ให้ใช้ไฟล์สำรอง

            สนับสนุนโครงการ

            Vocab Garden ใช้ฟรีและจะใช้ฟรีต่อไป ถ้าชอบแอปนี้ สนับสนุนให้โปรเจครันต่อไปได้ เงินที่ได้ใช้เป็นค่าใช้จ่ายของโปรเจค และเป็นกำลังใจในการแปลคำศัพท์เพิ่ม

            การสนับสนุนเป็นความสมัครใจ ไม่มีฟีเจอร์พิเศษสำหรับผู้สนับสนุน และชุดข้อมูลคำศัพท์ยังเป็น CC BY-SA 4.0 ใครก็นำไปใช้ต่อได้ตามเงื่อนไข ลิงก์ด้านบนพาไปยังบริการภายนอก แอปนี้ไม่รับชำระเงินเอง และการสนับสนุนนี้ไม่เกี่ยวข้องกับทีมผู้จัดทำ NGSL

            ความเป็นส่วนตัว

            • ความคืบหน้า การตั้งค่า ประวัติการทวนรายวัน และวันพักของสตรีค เก็บอยู่ในเครื่องของคุณเท่านั้น (ที่ localStorage คีย์ขึ้นต้นด้วย vg:) ไม่ถูกส่งออกไปที่ไหน
            • ไม่มีการสมัครสมาชิก ไม่มีคุกกี้ ไม่มีโฆษณา และไม่มีเครื่องมือวิเคราะห์หรือติดตามผู้ใช้
            • เสียงอ่านใช้บริการเสียงของเครื่องและเบราว์เซอร์ของคุณ บางเบราว์เซอร์อาจส่งข้อความที่อ่านไปประมวลผลกับผู้ให้บริการเสียงของเบราว์เซอร์นั้น ซึ่งเป็นไปตามนโยบายของเบราว์เซอร์ ไม่ใช่ของแอปนี้
            • แอปโฮสต์บน GitHub Pages ซึ่ง GitHub อาจเก็บบันทึกการเข้าถึงเว็บ (เช่น ที่อยู่ IP) ตามนโยบายของ GitHub และปุ่มแจ้งคำแปลผิดจะพาคุณไปที่ GitHub โดยข้อมูลจะถูกส่งก็ต่อเมื่อคุณกดส่งเอง
            • ลบข้อมูลทั้งหมดได้ที่ ตั้งค่า → ล้างความคืบหน้าทั้งหมด หรือล้างข้อมูลเว็บไซต์ในเบราว์เซอร์
