                        เกม 🎮

                        เกมสั้น ๆ ที่ใช้คำที่แปลแล้ว เล่นแล้วนับเป็นวันท่องต่อเนื่อง 🔥 แต่ไม่เปลี่ยนวันทวนของคำและไม่นับเป็นเป้าหมายรายวัน

                        🎯 คำที่ใช้เล่น

                        เลือกครั้งเดียว ใช้กับแฟลชการ์ด จับคู่คำ เรียงตัวอักษร และฟังแล้วเลือก (ทายคำปริศนาประจำวันใช้คำชุดเดียวกันทุกคน จึงไม่ขึ้นกับตัวเลือกนี้)

                        เลือกแปลง

                        สถานะของคำ

                        🌰 ยังไม่เรียน = ยังไม่เคยปลูก · 🌱 กำลังเรียน = ต้นอ่อนและกำลังโต · 🌳 เรียนแล้ว = ต้นไม้ใหญ่

                        • 🃏 แฟลชการ์ดเลือกแปลงและสถานะของคำ (ยังไม่เรียน / กำลังเรียน / เรียนแล้ว) แล้วพลิกการ์ดทบทวนตามใจ
                        • 🧩 จับคู่คำจับคู่คำอังกฤษกับคำแปลไทย 6 คู่ให้เร็วที่สุด
                        • 🎧 ฟังแล้วเลือกฟังเสียงอ่านโดยไม่เห็นตัวสะกด แล้วเลือกคำแปลไทยที่ถูก 8 ข้อ (ต้องเปิดเสียงเครื่อง)
                        • ⌨️ ฟังแล้วพิมพ์ฟังเสียงอ่านแล้วพิมพ์คำอังกฤษที่ได้ยิน 6 ข้อ ฝึกสะกดไปพร้อมกัน (ต้องเปิดเสียงเครื่อง)
                        • 🔤 ทายคำปริศนาเดาคำอังกฤษ 5 ตัวอักษรภายใน 6 ครั้ง วันละข้อ ทุกคนได้คำเดียวกัน
                        • 🔀 เรียงตัวอักษรดูคำแปลไทยแล้วเรียงตัวอักษรที่สลับไว้ให้เป็นคำอังกฤษ 5 ข้อ

                                มีอะไรใหม่ ✨

                                ประวัติการเปลี่ยนแปลงของ Vocab Garden เวอร์ชันใหม่อยู่บนสุด

                                โหลดประวัติไม่ได้ในตอนนี้ (อาจกำลังออฟไลน์) ดูได้ที่ CHANGELOG บน GitHub

                                ตั้งค่า

                                รู้ศัพท์แปลงแรก ๆ อยู่แล้วใช่ไหม? เลือกแปลงที่อยากเริ่ม คำใหม่จะมาจากแปลงนี้เป็นต้นไป คำที่ถึงเวลาทวนยังมาตามปกติ และแตะที่แปลงในหน้าหลักเพื่อเรียนเฉพาะแปลงนั้นได้เสมอ

                                🧭 ทดสอบวัดระดับ ช่วยเลือกแปลงเริ่มต้น

                                เสียงอ่าน

                                บางเครื่อง (เช่น iPhone) อาจต้องแตะหน้าจอหนึ่งครั้งก่อน เสียงจึงจะเล่นอัตโนมัติ เสียงมาจากเครื่องของคุณ ถ้าไม่ได้ยินให้เช็คว่าไม่ได้ปิดเสียงเครื่องไว้

                                วิธีทวน

                                "ผสมหลายแบบ": คำใหม่ยังเป็นการ์ดให้ดูก่อน ต้นอ่อน 🌱 ตอบด้วยการเลือกคำแปล ต้นกำลังโต 🌿 เติมคำที่หายไปในประโยคตัวอย่าง ส่วนต้นไม้ใหญ่ 🌳 ดูคำแปลไทยแล้วพิมพ์คำอังกฤษเอง (ถ้าไม่อยากพิมพ์ ปิดช่องด้านบนได้ ต้นไม้ใหญ่จะเติมคำแทน) ตอบถูกนับเป็น "จำได้แม่น" ตอบผิดหรือกด "ไม่รู้" นับเป็น "ยังจำไม่ได้" พิมพ์ถูกแต่ใช้ตัวช่วยใบ้ หรือสะกดผิดแค่ตัวเดียว นับเป็น "พอจำได้" การนึกคำเองช่วยให้จำได้นานกว่าการพลิกดูคำแปลอย่างเดียว

                                นิสัยการท่อง

                                แบ่งการท่องเป็นรอบย่อย จบแต่ละรอบจะถามว่าจะไปต่อหรือพักก่อน (ที่ทวนไปแล้วบันทึกไว้เรียบร้อย) เริ่มง่ายขึ้นเพราะแค่ไม่กี่นาทีก็จบรอบได้

                                นับเป็นจำนวนครั้งที่ตอบ ถ้าคำค้างทวนเยอะกว่าเพดาน แอปจะทยอยทวนวันละส่วน (เริ่มจากคำที่ค้างนานสุด) และงดคำใหม่ชั่วคราวจนกว่าคำค้างจะเบาลง ตั้ง "ไม่จำกัด" ถ้าอยากทวนให้หมดในวันเดียว การแตะเรียนเฉพาะแปลงจากหน้าหลักไม่ถูกจำกัดด้วยเพดานนี้

                                ความสนุก

                                ปิดไว้เป็นค่าเริ่มต้น เผื่อคุณท่องในที่สาธารณะ เสียงสร้างในเครื่องไม่มีการโหลดอะไรเพิ่ม แรงสั่นใช้ได้เฉพาะ Android (iPhone ไม่รองรับ) ส่วนคอนเฟตตีจะหยุดเองถ้าเครื่องตั้ง "ลดการเคลื่อนไหว"

                                หน้าตา

                                เลือก "ด้านบน" เพื่อย้ายปุ่มเมนูหลักจากด้านล่างจอไปอยู่ในแถบด้านบนฝั่งขวา เหมือนเมื่อเปิดบนเว็บเบราว์เซอร์ในคอม ใช้กับมือถือและ iPad (จอคอมที่ใช้เมาส์แสดงเมนูด้านบนอยู่แล้ว)

                                เตือนให้มาท่อง

                                สร้างนัดในแอปปฏิทินของเครื่อง ซ้ำทุกวันตามเวลาที่เลือก แล้วแอปปฏิทินจะแจ้งเตือนเอง ไม่ต้องอนุญาตการแจ้งเตือนของเว็บ และไม่มีข้อมูลใด ๆ ออกจากเครื่องคุณ

                                กดแล้วจะได้ไฟล์ .ics ให้เปิดด้วยแอปปฏิทิน (บน iPhone / iPad กด "เพิ่มทั้งหมด") ถ้าไม่อยากเตือนแล้ว ลบนัดนี้ในแอปปฏิทิน

                                ใช้ได้เมื่อเพิ่มแอปลงหน้าจอโฮมแล้ว ตัวเลขอัปเดตตอนเปิดแอปและตอนทวนเท่านั้น (แอปไม่มีเซิร์ฟเวอร์ที่ส่งแจ้งเตือนมาเอง) บน iPhone / iPad ต้องอนุญาตการแจ้งเตือนของแอปนี้ก่อนตัวเลขจึงจะขึ้น ไม่มีข้อมูลใด ๆ ออกจากเครื่อง

                                สำรองความคืบหน้า

                                ความคืบหน้าเก็บอยู่ในเครื่องนี้เท่านั้น ส่งออกไฟล์สำรองเก็บไว้ (เลือกบันทึกลงไฟล์ AirDrop หรือส่งเมลได้) หรือใช้ย้ายไปเครื่องอื่นได้

                                🔄 ใช้หลายเครื่อง: นำเข้าไฟล์จะ รวม กับความคืบหน้าในเครื่อง คำที่มีทั้งสองฝั่งจะเอาฝั่งที่ตอบล่าสุด ไม่ทับกัน ส่งออกไฟล์ไปเก็บใน iCloud Drive หรือ Google Drive แล้วเปิดนำเข้าที่อีกเครื่องได้ (ใช้การตั้งค่าจากไฟล์เฉพาะตอนเครื่องนี้ยังไม่มีความคืบหน้า)

                                💡 บน iPhone และ iPad: Safari กับแอปที่เพิ่มไว้บนหน้าจอโฮมเก็บข้อมูลแยกกัน แนะนำให้เปิดจากไอคอนบนหน้าจอโฮมเป็นหลัก ถ้าจะย้าย ให้ใช้ไฟล์สำรอง

                                🕘 สำเนาอัตโนมัติในเครื่อง

                                แอปเก็บสำเนาต้นวันย้อนหลัง 7 วัน และสำเนาก่อนนำเข้า ล้าง หรือกู้คืนอีก 3 ชุด ไว้กู้คืนเมื่อกดผิด กดเก็บสำเนาเองได้อีก 5 ชุดล่าสุด สำเนาอยู่ในเบราว์เซอร์ของเครื่องนี้ ถ้าล้างข้อมูลเว็บไซต์หรือเครื่องหาย สำเนาก็หายไปด้วย จึงไม่ใช่ที่สำรองจริง ยังควรส่งออกไฟล์ไว้

                                  ความเป็นส่วนตัว

                                  • ความคืบหน้า การตั้งค่า ประวัติการทวนรายวัน สถิติรายวัน (คำใหม่ ต้นไม้ใหญ่ ครั้งที่ตอบไม่ได้) วันพักของสตรีค โน้ตช่วยจำที่คุณเขียน สถิติเกม เหรียญ และดอกไม้ที่ได้ เก็บอยู่ในเครื่องของคุณเท่านั้น (ที่ localStorage คีย์ขึ้นต้นด้วย vg:) ไม่ถูกส่งออกไปที่ไหน แอปยังเก็บสำเนาอัตโนมัติของข้อมูลเหล่านี้ไว้ในเบราว์เซอร์ของเครื่องนี้ (IndexedDB ชื่อ vg-snapshots) ลบได้ที่ ตั้งค่า → สำเนาอัตโนมัติในเครื่อง
                                  • ไม่มีการสมัครสมาชิก ไม่มีคุกกี้ ไม่มีโฆษณา และไม่มีเครื่องมือวิเคราะห์หรือติดตามผู้ใช้
                                  • เสียงอ่านใช้บริการเสียงของเครื่องและเบราว์เซอร์ของคุณ บางเบราว์เซอร์อาจส่งข้อความที่อ่านไปประมวลผลกับผู้ให้บริการเสียงของเบราว์เซอร์นั้น ซึ่งเป็นไปตามนโยบายของเบราว์เซอร์ ไม่ใช่ของแอปนี้
                                  • แอปโฮสต์บน GitHub Pages ซึ่ง GitHub อาจเก็บบันทึกการเข้าถึงเว็บ (เช่น ที่อยู่ IP) ตามนโยบายของ GitHub และปุ่มแจ้งคำแปลผิดจะพาคุณไปที่ GitHub โดยข้อมูลจะถูกส่งก็ต่อเมื่อคุณกดส่งเอง
                                  • ลบข้อมูลทั้งหมดได้ที่ ตั้งค่า → ล้างความคืบหน้าทั้งหมด หรือล้างข้อมูลเว็บไซต์ในเบราว์เซอร์
