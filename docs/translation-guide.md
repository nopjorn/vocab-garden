# คู่มือการแปลคำศัพท์

คู่มือนี้ใช้กับไฟล์ชุดข้อมูล `app/data/levels/*.tsv` ทุกข้ออยู่ใต้กฎข้อ 1 ใน [CLAUDE.md](../CLAUDE.md) (ยึดเงื่อนไขของ NGSL เสมอ)

## โครงไฟล์

ด่านละ 1 ไฟล์ (`01.tsv` … `28.tsv` และ `sup.tsv`) คั่นคอลัมน์ด้วย tab ใช้ UTF-8 และ line ending แบบ LF

| คอลัมน์ | ใครเขียน | ตัวอย่าง |
|---|---|---|
| `rank` | มาจาก NGSL (ห้ามแก้) | `67` |
| `headword` | มาจาก NGSL (ห้ามแก้) | `work` |
| `forms` | มาจาก NGSL (ห้ามแก้) | `works, worked, working, workings` |
| `meanings` | ผู้แปล | `v: ทำงาน, ใช้การได้ \| n: งาน, ผลงาน` |
| `example_en` | ผู้แปล | `I work at a small hotel.` |
| `example_th` | ผู้แปล | `ฉันทำงานที่โรงแรมเล็ก ๆ แห่งหนึ่ง` |
| `note` | ผู้แปล (ไม่บังคับ) | คำอธิบายวิธีใช้ หรือหมายเหตุคำพ้องรูป |

- คอลัมน์ของ NGSL สร้างด้วย `python3 scripts/build_skeleton.py` และ CI ตรวจว่าตรงกับไฟล์ต้นฉบับทุกคำ
- คำที่ยังไม่แปล ให้เว้นคอลัมน์ภาษาไทยว่างทั้งหมด คำที่เริ่มแปลแล้วต้องมี `meanings`, `example_en` และ `example_th` ครบ
- ห้ามใส่ tab หรือขึ้นบรรทัดใหม่ในช่อง และห้ามมีช่องว่างหัวหรือท้ายช่อง

## ความหมาย (`meanings`)

- รูปแบบ `ชนิดคำ: คำแปล, คำแปล` ถ้ามีหลายชนิดคำให้คั่นด้วย ` | ` เช่น `v: ทำงาน, ใช้การได้ | n: งาน, ผลงาน`
- ใส่ 1–3 ความหมายที่ใช้บ่อย เรียงจากใช้บ่อยที่สุด เขียนเป็นภาษาไทยที่เป็นธรรมชาติ
- ความหมายต้องสอดคล้องกับรูปคำ (`forms`) ที่ NGSL ระบุ
- ชนิดคำที่ใช้ได้:

| รหัส | ชนิดคำ | รหัส | ชนิดคำ |
|---|---|---|---|
| `n` | คำนาม | `prep` | คำบุพบท |
| `v` | คำกริยา | `conj` | คำสันธาน |
| `adj` | คำคุณศัพท์ | `det` | คำนำหน้านาม/คำบ่งชี้ |
| `adv` | คำกริยาวิเศษณ์ | `num` | คำบอกจำนวน |
| `pron` | คำสรรพนาม | `int` | คำอุทาน |
| `aux` | กริยาช่วย | `modal` | กริยาช่วยแสดงความเป็นไปได้/ความจำเป็น |

## ประโยคตัวอย่าง (`example_en`, `example_th`)

- แต่งขึ้นใหม่เองทั้งหมด ห้ามคัดลอกจากพจนานุกรม เว็บ หรือแอปอื่น
- ใช้คำง่าย ไม่เกิน 12 คำ ระดับ A1–B1 และต้องมีคำหลักหรือรูปคำของคำนั้นอยู่ในประโยค
- คำแปลภาษาไทยต้องอ่านเป็นธรรมชาติ ไม่แปลทีละคำ

## คำไวยากรณ์

คำอย่าง the, of, to, a ที่แปลตรงตัวไม่ได้ ให้ใส่ความหมายสั้น ๆ ใน `meanings` แล้วอธิบายวิธีใช้ใน `note` เช่น the → `note`: ใช้นำหน้าคำนามที่ทั้งผู้พูดและผู้ฟังรู้ว่าหมายถึงสิ่งไหน

## คำพ้องรูป

NGSL แยกความหมายของคำพ้องรูปผ่านรูปคำอยู่แล้ว ให้แปลตามรูปคำของการ์ดนั้น แล้วใส่ `note` ชี้ไปอีกความหมาย

| คำหลัก | รูปคำใน NGSL | แปลว่า | อีกความหมายอยู่ที่การ์ด |
|---|---|---|---|
| `found` | founds, founded, founding | ก่อตั้ง | `find` (found = รูปอดีตของ find) |
| `left` | lefts | ซ้าย | `leave` (left = รูปอดีตของ leave) |
| `rose` | roses | ดอกกุหลาบ | `rise` (rose = รูปอดีตของ rise) |
| `wound` | wounds, wounded, wounding | บาดแผล, ทำให้บาดเจ็บ | `wind` (wound = รูปอดีตของ wind) |
| `mine` | mines, mined, mining | เหมือง, ขุด | `I` (mine = ของฉัน) |

## แหล่งข้อมูล

- ใช้ความรู้ของผู้แปลเป็นหลัก
- ถ้าจำเป็นต้องอ้างอิงแหล่งอื่น ใช้ได้เฉพาะ CC0 / CC BY / CC BY-SA และต้องให้เครดิต ถ้าไม่แน่ใจ ให้แจ้ง 🚨 NGSL Alert ก่อน
- ถ้าเจอข้อผิดพลาดในข้อมูลของ NGSL อย่าแก้เอง ให้แจ้งเจ้าของโปรเจค
